en:
# VFWatchDialSDK

VFWatchDialSDK is a pre-compiled SDK full of development tools for watch face preview generation and compiling watch faces for smartwatches that use the VeryFit app.

## Important Notes
Sideloading watch faces with custom layouts may void the device warranty or corrupt the device. If you are a Sifli/SiChe user (e.g. GTX13), then this SDK is not for your device.

# VFWatchDialSDK

VFWatchDialSDK 是一套预编译的 SDK，包含用于生成表盘预览图及编译表盘文件的开发工具，适用于使用 VeryFit 应用程序的智能手表。

## 重要提示
侧载具有自定义布局的表盘可能会导致设备保修失效或设备损坏。如果您使用的是 Sifli/SiChe 平台设备（例如 GTX13），则该 SDK 不适用于您的设备。
